What production taught me

    
Lessons you only learn at 3 a.m.

    
    
PULSAR
A steady heartbeat: health checks every 15 s, never skipped
hover to engage

      
01
Healthy is not the same as working.

        
I once watched a container report healthy while serving 500s after an OutOfMemoryError. Now I check what the user actually sees, and I make failures loud.

      
02
Automate the night-shift fix.

        
If I've restarted it by hand at night, it should be a restart policy, a pipeline or an alarm. People should handle judgement calls, not routine restarts.

      
03
Every change needs a way back.

        
Weekend release windows taught me to plan for rollback first: reviewed plans, immutable build tags, and a redeploy that takes minutes, not a war room.

      
04
Least privilege, by default.

        
Certificates, keystores, CVEs and Okta SSO integrations are daily work for me. In the cloud that means no SSH, IAM roles instead of keys, one-IP access, and no secrets in Git.

01 · PROBLEM
Certificates expire quietly
I renew SSL certificates by hand in production. An expired one is an outage nobody saw coming. I wanted the warning before the failure.

        
02 · BUILT
Serverless watchdog + SSO
A Python Lambda on an EventBridge schedule, Telegram alerts, the token in SSM, and a dashboard behind Auth0 SSO with an API Gateway JWT authorizer. 13 resources in Terraform.

        
03 · DISCOVERED
Open doors in the identity provider
Old test users and four social logins could reach the new app. Locked it down to one connection and one admin-created user, with sign-ups off.

        
04 · VERIFIED
Proved both paths
Expired certificate caught from AWS and sent to my phone. No token → 401 before Lambda runs. SSO login → live results plus decoded JWT claims.
